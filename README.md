# Descripción General

Astro-Type es una herramienta educativa desarrollada bajo el enfoque de los **Serious Games**, videojuegos cuyo propósito principal es el aprendizaje y el desarrollo de habilidades específicas.

El juego busca apoyar el proceso de enseñanza de la ortografía y la mecanografía en estudiantes de distintos niveles académicos, combinando mecánicas de acción, desafíos progresivos y retroalimentación inmediata para generar una experiencia de aprendizaje atractiva y efectiva.

En Astro-Type, los jugadores deberán proteger su nave espacial de una lluvia de meteoritos que amenazan con destruirla. Cada meteorito contiene una palabra que deberá escribirse correctamente para eliminar la amenaza antes de que impacte.

Desarrollar un videojuego educativo que contribuya al fortalecimiento de las habilidades de ortografía y mecanografía mediante una experiencia lúdica e interactiva.

# Mecánicas de Juego

### 1. Defensa Espacial

El jugador controla una nave espacial ubicada en el centro de la pantalla.

### 2. Aparición de Meteoritos

Los meteoritos aparecen de manera progresiva desde diferentes direcciones del espacio.

### 3. Escritura de Palabras

Cada meteorito contiene una palabra que debe ser escrita exactamente como se muestra.

### 4. Destrucción de Objetivos

Al escribir correctamente la palabra:

✅ El meteorito es destruido.

❌ Si la palabra contiene errores, el meteorito continúa avanzando.

### 5. Sistema de Vidas

Cuando un meteorito impacta contra la nave:

* El jugador pierde vidas.
* Aumenta la presión del juego.

### 6. Incremento de Dificultad

Conforme avanza la partida:

* Los meteoritos son más rápidos.
* Aparecen más palabras simultáneamente.

# Instalación

## Clonar el repositorio

```bash
git clone https://github.com/JustinDPM/Serious-game-mecanografia.git
```

## Acceder al proyecto

```bash
cd astro-type
```

## Abrir en Godot

1. Abrir Godot Engine.
2. Seleccionar **Import Project**.
3. Elegir la carpeta del proyecto.
4. Ejecutar la escena principal.
